# Весовой дозатор сахара в мешки 25/50 кг — проект «Ливны»

Программа правления весовым дозатором для контроллера **ОВЕН СПК107**
(CODESYS 3.5.17), написанная на **Structured Text (IEC 61131-3)**
с комментариями на русском языке.

**Оборудование:**

| Устройство | Назначение | Сеть |
|---|---|---|
| ОВЕН СПК107 | ПЛК + панель оператора 7" | Ethernet (программирование) |
| МВ110-224.1ТД | 1 канал тензодатчика (вес) | RS-485, адрес 16 |
| МВ110-8Д.4Р | 8 дискретных входов / 4 реле | RS-485, адрес 17 |

Связь с модулями — через официальные **ФБ-шаблоны МХ110 для CODESYS 3.5**
(протокол ОВЕН / Modbus RTU, 115200 8N1).

| Файл | Объект | Назначение |

| `04_FB_WeightChannel.st` | ФБ | Watchdog связи, ЭМА-фильтр, стабильность, тара, скорость потока |

маппинг на шаблонные ФБ модулей выполняется интегратором в CODESYS
(таблица связки — ниже).

## Алгоритм (кратко)

Цикл: `ГОТОВНОСТЬ → ЗАЖИМ → ТАРА → ГРУБО → ТОЧНО → УСПОКОЕНИЕ → КОНТРОЛЬ (→ ДОСЫПКА) → СБРОС → ПАУЗА`.

1. **Двухступенчатая подача** — основной шнек ~90 % дозы, малый шнек — доводка.
2. **Отсечка «на лету»**: питатель закрывается заранее, `W_отс = W_зад − Δ_лету`.
3. **Адаптация Δ** по ошибке каждой дозы: `Δ := clamp(Δ + 0,3·ε, 0,02…0,8 кг)`.
4. **Контроль потока** — ранняя диагностика затора шнека / пустого бункера.
5. **Досыпка** при недовесе (до 3 попыток), передоз — авария с ручной выгрузкой.
6. **Failsafe** — аварийный стоп и потеря весов гасят выходы в том же скане.

Точность: допуск ±50 г (0,2 % — жёстче ГОСТ 8.579-2002: для 15–50 кг допустимо ±1 %).

## Связывание переменных (маппинг в CODESYS)

**МВ110-224.1ТД** (ФБ `Mv110Td`):

| Шаблон модуля | GVL |
|---|---|
| значение веса, кг | → `g_rWeightRaw` |
| данные достоверны | → `g_xWeightValid` |
| ошибка модуля | → `g_xWeightErr` |
| вход «тара/ноль» | ← `g_xTareToModule` |

**МВ110-8Д.4Р** (ФБ `Mv110_8D4R`):

| Канал | GVL | Назначение |
|---|---|---|
| DI0…DI7 | `g_xDiStart … g_xDiCoverClosed` | Пуск · Стоп · Аварийный стоп (НЗ!) · Мешок в зоне · Концевик зажима · Давление воздуха · Уровень бункера · Крышка |
| DO0…DO3 | `g_xDoClamp, g_xDoCoarse, g_xDoFine, g_xDoSignal` | Зажим · Грубый шнек · Точный шнек · Лампа/зуммер |

Экран СПК107 привязывается к `g_Hmi.*`, `g_xHmi*`, `g_Manual.*`,
`g_rHmiSetpoint`, `g_xManualMode`.

## Задачи

- Основная задача: `PRG_Main` — цикл 20 мс;
- Сервисная: `PRG_HMI` — цикл 50–100 мс.

## Пусконаладка

1. РУЧНОЙ режим — проверить каждое реле и каждый вход по очереди.
2. Калибровка весов в Owen Configurator (ноль → гиря известного веса).
3. Подбор `rCoarseCutoff` (8–12 % дозы) и `rInFlightInit` (0,1–0,3 кг);
   адаптация доработает за 10–20 циклов.
4. Прогнать 10 циклов, проверить `g_Stats` и тренд `rInFlight`.
5. Проверить аварийные сценарии: Е-стоп, обрыв RS-485, затор, передоз.
